# SQL 스터디 Day01

## DAY 01 Study | 💬 SQL(Structured Query Language) 이란?
관계형 데이터베이스에서 사용되고, 데이터베이스를 조작하는 언어

### 🗂️ 데이터베이스 (Data Base, DB)란?
`데이터의 집합`을 정의 
* 특정 조직을 이용하는데 필요한 데이터(공용 데이터)를 컴퓨터의 기억장치 (디스크) 공간에 모아놓은 데이터 집합 
* 데이터의 저장공간 자체를 의미하기도 함 
* MySQL에서는 데이터베이스를 자료가 저장되는 디스크 공간 자체로 취급한다. 

### 데이터 베이스의 중요 의미
1. 데이터베이스는 `공용 데이터(Shared Data)`이다.
2. 데이터베이스는 `통합 데이터(Integrated Data)`이다. *중복을 최소화 한다. 
3. 데이터베이스는 `저장 데이터(Stored Data)`이다.
4. 데이터베이스는 `운영 데이터(Operational Data)`이다.

### 데이터 베이스의 특징
1. 데이터의 무결성 : 제약조건을 통한 정확한 정보 
2. 데이터의 독립성 : 데이터베이스를 건들여도 기존에 작성된 응용프로그램은 영향 받지 않음 
3. 보안 : 허용된 사람만 데이터에 접근 가능 
4. 데이터 중복의 최소화 
5. 데이터 안정성 향상 : DBMS에 의한 관리, 백업 및 복원 가능 
6. 내용에 의한 참조 : 요구하는 데이터의 값에 의해 데이터가 어디에 저장되어 있던지 참조되어 찾을 수 있다. 
7. 동시, 실시간 접근 및 공유 : 조직과 사용자에게 동시에 공유하고 실시간으로 변화된 내용을 반영한다. 

> DBMS의 궁극적 목적은 데이터의 독립성이다. 

### 데이터베이스 관리 시스템, DBMS(Data Base Management System)이란?
데이터베이스를 관리하고 운영하기 위한 소프트웨어
* DBMS를 통하여 데이터에 동시에 접속하고 공유하며, 데이터를 집중적으로 관리 
* 파일시스템의 데이터 중복성, 데이터 종속성 등의 단점을 보완하기 위하여 등장 

### DBMS의 분류 
1. 계층형 DBMS (Hierarchical DBMS)
2.   망형 DBMS (Network DBMS)
3. 관계형 DBMS (Relational DBMS)
4. 객체관계형 DBMS (Object-Relational)

### 관계형 데이터 베이스 (RDBMS)
테이블이라 불리는 최소단위로 구성되어, 속성과 value 값에 따라 행과 열로 구성된 데이터베이스 구조 
* 테이블을 부르는 다른 용어로는, `릴레이션`, `엔티티` 등이 있다. 
* 테이블들의 관계를 기본키(PK)와 외래 키(FK)를 사용해 부모자식 관계로 맺어줄 수 있다.
* 다른 DBMS에 비해 업무가 변화될 경우 쉽게 변화에 순응 할 수 있는 구조로 유지보수 측면에서 편리하다. 
* 대용량 데이터의 관리와 데이터 무결성 보장을 잘 해준다.
* 동시에 데이터에 접근하는 응용프로그램을 사용할 때 good 
* 시스템 자원을 많이 차지하여 전반적으로 느려질 수 있다. 

### SQL 의 특징
* 표준 SQL은 대부분의 DBMS 제품에서 공통적으로 호환된다. 
* 즉, SQL을 다른 시스템으로 이식할 때 별 문제가 없다. 
* 대화식 언어로 구성되어있어 바로 질의하고 결과를 얻을 수 있다. 
* 분산형 클라이언트, 서버 구조이다. 

### SQL의 종류
1. 데이터 정의어 (DDL)
2. 데이터 조작어 (DML)
3. 데이터 제어어 (DCL)

## SELECT 문 정리
```sql
-- 데이터베이스, 데이터 테이블 사용 
USE 데이터테이블명; 

-- 별칭으로 바꿔서 데이터 가져오기 
SELECT 속성명 AS 별칭 -- AS 생략 가능, 띄어쓰기 포함된 별칭 ''로 감싸기 
FROM 데이터테이블명

-- 데이터테이블에서 특정 조건 데이터 받는 명령어 
SELECT 속성명
FROM 데이터테이블명
WHERE 조건식 


-- 조건식 
WHERE 속성 >= 기준 -- 연산 기호
WHERE 조건식 AND 조건식 -- 두조건 모두 충족 되는 조건 반환
WHERE 조건식 OR 조건식 -- 두조건 중 하나만 충족하면 조건 반환
WHERE 속성명 BETWEEN 조건1 AND 조건2; -- 조건1 이상 조건2 이하 
WHERE 속성명 IN('조건1','조건2',...); -- =OR, IN() 함수 안에 조건 중 맞는 데이터 반환 
WHERE 속성명 LIKE '%검색어'; -- 문자열 내용 검색 %는 검색어가 포함되어있는 단어 중 그 앞은 무엇이든 허용한다는 뜻
WHERE 속성명 LIKE '검색어_'; -- _는 검색어 뒤에 한글자 매치 (언더바 만큼)

-- 조건식 사용 예시 (BETWEEN) 
WHERE height BETWEEN 180 AND 183; -- (=height >= 180 AND height <= 183;)

-- 조건식 사용 예시 (LIKE)
WHERE name LIKE '김%' -- 김씨 성을 가진 모든 사람 정보 반환 
WHERE name LIKE '_다래' -- 성이 한글자이고 이름이 다래인 모든 사람 정보 반환 

-- 서브쿼리 : 쿼리문 안에 쿼리문이 들어가 있는 것 
SELECT *
FROM usertbl
WHERE height >= (SELECT height FROM usertbl WHERE addr = '서울'); -- 주소지가 서울인 사람의 정보의 키보다 크거나 같은 정보 반환 

SELECT *
FROM usertbl
WHERE height >= ANY (SELECT height FROM usertbl WHERE addr = '서울'); -- ANY (or SOME): 한가지만 만족해도 OK 

SELECT *
FROM usertbl
WHERE height >= ALL (SELECT height FROM usertbl WHERE addr = '서울'); -- ALL : 서브쿼리 결과가 여러개일 경우, 결과가 모두 만족하는 조건만 반환.. 

/* 결국 서울에 사는 사람이 여러명인데 키가 170도 있고, 180도 있으면 180이상인 사람만 반환 */ 
```
