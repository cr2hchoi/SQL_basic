# SQL 스터디 Day02 

## SQL의 분류 
### 1. DML (Data Manipulation Language) :데이터 조작어 
> 데이터를 조작하는데 사용되는 언어
> 데이터 선택, 삽입, 수정, 삭제 할 때 사용되는 언어이다 
> 
* 예시 : SELECT, INSERT, UPDATE, DELETE 
** 트랜잭션이 발생하는 SQL문이다 (임시저장-복구가능)

### 2. DDL (Data Definition Language) : 데이터 정의어
> 데이터베이스 개체를 생성/삭제/변경하는 역할을 함 
>
* 예시 : CREATE, DROP, ALTER 

### 3. DCL (Data Control Language) : 데이터 제어어
> 사용자에게 권한을 부여하거나 빼앗을 때 사용하는 구문
> 
* 예시 : GRANT, REVOKE, DENY
